# 아하루프 × 삼쩜삼 비즈니스 비교 v1.0

작성일: 2026-09-14  
근거 범위: 삼쩜삼·삼쩜삼 비즈니스의 공개 웹 화면과 고객센터. 로그인 후 개인화 알림, 내부 발송 규칙과 성과는 확인하지 않았으며 추정하지 않는다.

## 결론

삼쩜삼 비즈니스는 사장님의 세금 일정, 사업 지원금과 세무 서비스를 빠르게 확인하게 하는 사업자 중심 서비스다. 아하루프는 전 생애주기 사용자의 현금·할인·교육·돌봄·안전 혜택을 공식 근거로 판정하고, 발견부터 실제 수령·이용까지 관리하는 혜택 회수 서비스로 포지셔닝한다.

단순히 혜택 수가 더 많다는 주장으로는 차별화되지 않는다. 차이는 `누가 대상인지`, `왜 맞는지`, `다음에 무엇을 할지`, `실제로 받았는지`를 하나의 데이터 흐름으로 연결하는 데 있다.

## 공개 화면에서 배울 패턴

- 일정 중심: 월별 세금·지원금 일정을 한눈에 제시한다.
- 결과 중심: 금액과 마감을 짧고 강하게 보여 준다.
- 낮은 인지 부담: 짧은 설명과 명확한 CTA로 다음 화면을 연다.
- 상시 정보와 시기성 공고를 함께 둔다.

## 아하루프 적용

- 일반 일정판이 아닌 `내가 놓치면 안 될 혜택 일정`을 만든다.
- 금액만 강조하지 않고 월간·1회성·비현금 가치와 판정 근거를 함께 표시한다.
- 알림을 새 발견, 마감 임박, 진행 이어가기, 수령 확인으로 나눠 고객 상태에 맞춰 보낸다.
- 질문 또는 다음 행동은 한 알림에 하나만 둔다.
- 광고와 제휴는 혜택 판정·추천 순위에서 분리하고 명확히 표시한다.

## 차별화 검증 지표

- 알림 CTA 이후 조건 확인 완료율
- 마감 전 준비·신청 완료율
- 알림이 기여한 실제 수령·서비스 이용 완료율
- 중복·무관 알림 신고율과 알림 끄기율
- 판정 근거 확인 후 정정 요청률

## 브랜드 판단

`아하루프`는 친근하고 확장성이 있으며, 몰랐던 혜택을 발견하는 `아하`와 수령까지 이어지는 `루프`가 제품 구조와 맞는다. 반면 이름만으로 혜택 범주가 드러나지 않는 약점이 있다. 마스터 브랜드는 유지하고 `아하루프 | 놓친 혜택을 받을 때까지`, 알림 채널에는 `아하루프 혜택알림`을 병기한다.
