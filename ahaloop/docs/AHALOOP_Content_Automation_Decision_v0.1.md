# 아하루프 콘텐츠 자동 수집 의사결정서 v0.1

상태: **검수형 파일럿 실행 — 광고 상품 모델은 별도 미확정**

작성일: 2026-09-11

목적: 뉴스, 행사·공모전, 참고자료, 학술자료, 채용·기회를 합법적이고 반복 가능한 방식으로 수집해 검수 대기 카드로 만드는 기준을 정한다.

> 2026-09-11 사용자 요청에 따라 실제 자료를 수집해 사이트에서 검증하는 파일럿을 시작했다. 초기 고객군은 스타트업의 사업개발·전략, 분야는 AI·B2B SaaS·고객 경험으로 두고 모든 카드는 수동 검수한다. 광고 영역은 수요 측정용 예시이며 실제 광고주·상품으로 오인시키지 않는다.

## 1. 수집 원칙

- API, RSS, 공공데이터처럼 제공자가 허용한 구조화 경로를 먼저 사용한다.
- 제목, 원문 URL, 제공자, 게시일, 마감일, 식별자와 허용된 요약 정보만 저장한다. 기사·논문·자료 원문 전체를 복제하지 않는다.
- 임의 웹 스크래핑은 이용약관, robots 정책, 저작권과 재배포 조건을 출처별로 검토한 뒤 별도 승인한다.
- 수집된 항목은 모두 `검수 대기` 상태로 저장한다. 초기 서비스에서는 운영자가 출처, 날짜, 마감, 요약과 개인화 이유를 확인해야만 발송 후보가 된다.
- 편집 추천과 광고를 분리한다. 스폰서 여부는 추천 점수에 영향을 주지 않으며 광고 카드는 항상 `광고`로 표시한다.

## 2. 1차 공식 수집원

|유형|1차 수집원|수집 방식|주기|필수 확인|
|---|---|---|---|---|
|뉴스|네이버 뉴스 검색 API|관심 분야·직무·기업 키워드 조합으로 JSON 검색|6시간|Client ID/Secret, 원문 URL, 게시 시점, HTML 태그 제거|
|행사·공모전·지원사업|K-Startup 사업공고·오픈 API|공식 공고 식별자와 모집 기간 중심 수집|하루 2회|공개 API 신청·명세 확인, 접수 마감·대상·지역|
|채용·기회|고용24 Open API|공식 채용 정보와 공고 식별자 수집|6시간|기업회원 가입·인증키 심사, 마감·직종·지역|
|학술·참고자료|Crossref REST API|DOI, 제목, 저자, 발행일, 저널, 라이선스 메타데이터 수집|하루 1회|초록의 별도 저작권, DOI 중복, 철회·수정 정보|
|학회·민간 행사|승인된 기관의 공식 RSS/API 또는 운영자 URL 등록|출처별 어댑터 또는 수동 등록|하루 1회|공식성, 일정 변경, 이용약관, 취소 여부|

공식 근거:

- 네이버 뉴스 검색 API: https://developers.naver.com/docs/serviceapi/search/news/news.md
- K-Startup: https://www.k-startup.go.kr/web/main/index.do
- K-Startup Open API 예시: https://nidview.k-startup.go.kr/view/public/kisedKstartupService/businessInformation
- 고용24 Open API: https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do
- Crossref REST API: https://www.crossref.org/documentation/retrieve-metadata/rest-api/

학회·민간 행사는 하나의 신뢰할 만한 통합 API가 없으므로 첫 버전에서 임의 크롤링 대상으로 삼지 않는다. 사용자가 선정한 기관 허용 목록부터 시작한다.

## 3. 자동화 흐름

```text
예약 실행
  → 출처별 수집 어댑터
  → 원본 메타데이터 보관
  → 정규화·중복 제거
  → 태그·요약·적합도 후보 생성
  → 품질 규칙 검사
  → 운영자 검수 대기
  → 승인 콘텐츠만 개인별 순위 산정
  → 이번 주 브리프/오호 추가 뉴스 구성
  → 발송·반응 기록
```

### 정규화와 중복 제거

- URL 추적 파라미터를 제거해 canonical URL을 만든다.
- 뉴스는 canonical URL과 정규화 제목, 지원사업·채용은 공식 공고 ID, 학술자료는 DOI를 1차 중복키로 쓴다.
- 제목의 공백·기호·HTML을 정리하고 유사 제목은 검수 화면에서 중복 후보로 묶는다.
- 모든 날짜는 원본 시간대와 함께 저장하고, 사용자 화면에서는 Asia/Seoul로 표시한다.

### 품질·안전 검사

- 마감이 지난 행사·채용·공모전은 신규 추천에서 제외한다.
- 출처 URL, 게시일 또는 마감일이 없거나 파싱이 불확실하면 자동 승인하지 않는다.
- 생성 요약은 제공된 메타데이터와 허용된 스니펫만 근거로 하며 투자·합격·지원 결과를 단정하지 않는다.
- 동일 출처가 한 회차를 독점하지 않게 하고, 뉴스·기회·자료의 유형 다양성을 확보한다.
- 취소·수정·철회가 확인되면 승인 카드도 즉시 보류하고 발송 전 다시 검사한다.

## 4. 개인화와 상품 규칙

- 사용자의 관심 분야 최대 2개, 관심 역할 최대 2개, 선택한 정보 유형만 후보에 넣는다.
- 점수는 `관심 일치 + 최신성 + 마감 임박도 + 과거 저장/실행 반응 - 반복 출처/중복 주제`로 구성한다.
- 기본 발송은 검수 완료 3~5개다.
- `오호, 더 보고 싶어요`를 누르면 현재 카드와 가장 가까운 관련 뉴스 1개를 즉시 열고, 그 뒤에 `광고` 표시가 있는 스폰서 카드 1개를 노출한다.
- 광고 카드에는 `더 많은 흐름으로 이어가고 싶나요?` CTA를 두고 클릭을 편집 반응과 분리된 `paid_loop_interest` 이벤트로 기록한다.
- 평가를 완료한 사용자는 다음 주 편집 콘텐츠에 관련 뉴스 1개를 추가한다. 이 보상은 광고 노출 조건이 아니다.
- 광고주는 편집 순위를 구매할 수 없으며, 광고 카드의 클릭·전환 지표는 편집 콘텐츠 지표와 분리한다.

## 5. 구현 단계

### 1단계 — 검수형 파일럿

- 기존 D1에 수집원, 원본 항목, 정규화 항목, 중복키, 검수 상태, 수집 실행 이력을 추가한다.
- 별도 Cloudflare Worker의 Cron Trigger가 수집을 실행하고 현재 서비스는 D1의 승인 콘텐츠만 읽는다.
- 출처 4종을 하루 2회 이하로 수집하고 모든 카드는 수동 검수한다.
- 실패는 재시도 횟수와 다음 재시도 시각을 기록한다.

### 2단계 — 안정화

- 출처가 5개를 넘거나 하루 후보가 1,000건을 넘으면 Queue로 수집·정규화 작업을 분리한다.
- 재시도와 Dead Letter Queue, 출처별 호출 한도, 장애 알림을 추가한다.
- 신뢰 출처에 한해 필드 완결성·중복·마감 검사 통과 시 자동 승인할지 별도 결정한다.

기술 근거:

- Cloudflare Cron Triggers: https://developers.cloudflare.com/workers/configuration/cron-triggers/
- Cloudflare Queues: https://developers.cloudflare.com/queues/reference/how-queues-works/

현재 Sites 배포 환경에서 Cron/Queue 바인딩 지원 여부는 구현 전에 확인한다. 지원되지 않으면 수집 Worker를 분리하고 서비스에는 승인 데이터만 전달한다.

## 6. 운영 지표

- 출처별 수집 성공률, 마지막 성공 시각, 오류율, API 호출량
- 수집 → 중복 제거 → 검수 대기 → 승인 → 발송 전환율
- 마감 오류, 깨진 링크, 중복 카드, 수정·철회 누락 건수
- 콘텐츠 유형별 열람·저장·실행·오호·검토 요청·평가율
- 편집 콘텐츠와 광고의 노출·클릭·전환을 분리한 지표

## 7. 파일럿 결정과 남은 결정

1. **초기 고객군과 키워드 — 파일럿 적용**: `초기 스타트업의 사업개발·전략 담당자`, `AI·B2B SaaS·고객 경험`으로 시작한다.
2. **검수 수준 — 파일럿 적용**: 모든 카드를 사람이 원문까지 확인하고 승인한다.
3. **유료 광고 모델 — 미확정**: 현재는 실제 광고를 판매하지 않고 `더 많은 흐름으로 이어가고 싶나요?` 클릭만 수요 신호로 측정한다. 직접 판매, 제휴, 자사 상품 중 무엇으로 시작할지는 별도로 정한다.

파일럿 수집 절차는 `.agents/skills/ahaloop-content-collector/SKILL.md`로 관리한다. 실제 예약 수집을 켜기 전에는 API 키, 실행 환경과 광고 상품 모델을 추가 확정한다.
