1. 원본 사진 자체를 웹사이트, 카카오톡 채널, 광고, 문서 또는 굿즈에 게시하지 않는다.
2. 최초 촬영자와 허가 범위를 확인하기 전까지 사진을 상업적 사용이 허가된 자료로 표시하지 않는다.
3. 공개 브랜드의 권리관계를 가장 명확하게 하려면 외부 사진을 입력하지 않고 텍스트 설명만으로 마스코트를 새로 제작한다.
4. 기존 결과물을 계속 사용할 경우 이 문서, 생성 프롬프트, 생성 시점, 결과물 원본 및 이후 사람의 편집 파일을 함께 보관한다.
5. 사진의 최초 출처나 라이선스를 추가로 확인하면 URL, 권리자, 허가 범위, 확인 일자와 증빙 사본 위치를 이 문서에 덧붙인다.
