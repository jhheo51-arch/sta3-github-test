# 아하루프 데이터 보관·삭제 기준 v1.0

## 최소 수집과 계정 분리

고객·운영 자료는 Sites가 전달한 로그인 사용자 ID로 분리합니다. 클라이언트가 보낸 사용자 ID, 공통 데모 계정, 이메일을 소유권 키로 사용하지 않습니다.

## 보관 기간

| 자료 | 보관 기준 | 목적 |
|---|---:|---|
| 발송 시도 기록 | 90일 | 중복 과금·재발송 방지 |
| 활동 이벤트·평가·발송·원문 검수 | 180일 | 접근 부담·진행·운영 품질 분석 |
| 후속 작업 | 365일 | 미처리 요청과 결과 추적 |
| 프로필·신청함·동의·포트폴리오·파일럿 기록 | 계정 삭제 전까지 | 서비스 진행과 사용자 요청에 따른 증거 보존 |

로그인한 계정이 서비스를 열 때 해당 계정의 만료 자료를 정리합니다. 이는 별도 예약 작업이 아니라 접속 시 실행되는 보관 정책입니다.

## 사용자가 직접 삭제하는 방법

`내 조건 → 내 데이터 보관·삭제 → 내 저장 자료 삭제`에서 확인 문구 `내 데이터 삭제`를 입력합니다. 프로필, 신청 진행, 이벤트, 알림 동의, 검수·파일럿 기록이 같은 요청에서 삭제됩니다. 공유 혜택 목록과 ChatGPT 계정 자체는 삭제하지 않습니다.

## 운영 권한

- 고객: 자신의 프로필·혜택·신청함·동의·이벤트만 접근
- 운영자: `AHALOOP_OPERATOR_USER_IDS` 서버 설정에 등록된 계정만 검증실·파일럿·실발송 테스트 접근
- 브라우저에서 탭을 숨기는 것과 별개로, 서버 API가 운영자 권한을 다시 검사

## 현재 한계

- 기관의 실제 지급 정보와 고객의 민감 서류는 저장하지 않습니다.
- 실제 발송업체 계정이 없으므로 발송은 잠겨 있습니다.
- 법률 자문을 대체하는 개인정보처리방침이 아니라 파일럿 제품의 데이터 운영 기준입니다. 공개 서비스 전에는 법률 검토와 문의·철회 절차를 추가해야 합니다.
