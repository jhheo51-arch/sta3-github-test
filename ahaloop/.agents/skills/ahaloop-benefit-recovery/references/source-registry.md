# 혜택 수집원과 신속성 기준

## 수집원 우선순위

- 2026-09-18에는 공식 공개 공고를 우선했다. 2026-09-26에는 온통청년 청년정책 API를 첫 공식 API 연결 대상으로 선택해 호출 코드와 오류 처리를 준비했다. 인증키 발급·성공 응답·예약 실행은 아직 미완료이며 아래는 연결 순서이지 현재 전국 수집 범위가 아니다.
- 첫 후보: 청년몽땅정보통 [정책 정보](https://youth.seoul.go.kr/infoData/plcyInfo/list.do), [청년지원정보](https://youth.seoul.go.kr/infoData/sprtInfo/list.do). 공개 목록 존재 확인, 자동 접근 이용 조건과 앱 연결은 미완료. 행사·활동과 금전·서비스 혜택을 구분한다.
- 전문·지역 확장 후보: 문화누리 등 기존 등록 공식 원문, 고용24·한국장학재단·국세청·아이돌봄·보건복지부 및 선정한 지자체 공고. 전체 기관 연결 완료로 해석하지 않는다.
- 전국 API 후보: 온통청년을 첫 연결 대상으로 진행하고, 행정안전부 대한민국 공공서비스와 복지로는 후속 후보로 둔다.

연결 전에는 각 제공기관의 이용약관, 재배포 허용범위, 호출 한도, 인증키 필요 여부를 확인한다. 검색 결과와 민간 요약은 발견 후보로만 쓰고 판정 원문으로 쓰지 않는다.

## 상태와 주기

2026-09-26 공식 API 재확인: [온통청년 이용방법](https://www.youthcenter.go.kr/cmnFooter/openapiIntro/oaiGuide)은 회원가입·인증키 신청·담당자 승인 절차와 HTTPS 제공을 안내한다. [제공목록](https://www.youthcenter.go.kr/cmnFooter/openapiIntro/oaiDoc)의 현재 정책 경로는 `/go/ythip/getPlcy`, 인증 매개변수는 `apiKeyNm`, 응답 선택은 `rtnType=json`이다. 아하루프는 이 호출과 오류 처리를 준비했지만 실제 키와 성공 응답 표본이 없다. 계정 발급 후 호출 한도·성공 스키마·재배포 조건을 다시 확인한다.

검증실은 등록 공식 URL의 단건 수동 실행, 성공/실패, 마지막 성공 기준 비교, 개인 검수 의견을 저장한다. 예약 운영과 다르고 검수 승인은 공개 규칙·발송을 자동 변경하지 않는다. 기관 게시 시각이 없으면 발견 지연은 미측정으로 둔다.

- `key_required`: 공식 API는 확인했지만 인증키가 없어 실행 전.
- `api_configured`: 서버 비밀 설정에 인증키를 연결했지만 성공 호출·예약 실행 전.
- `monitor_ready`: 공식 페이지와 변경 필드는 정했지만 예약 실행 전.
- `manual_verified`: 운영자가 공식 원문을 확인한 대표 데이터.
- `running`: 예약 실행과 마지막 성공 시각이 모두 있는 자동 수집. 실제 연결 뒤에만 사용한다.

기존 60/180/30분은 미측정 목표이며 실제 약속이 아니다. 공개 페이지 방식은 허용 범위 확인 후 새 목록 1~3시간, 장기·상시 공고 하루 1회 확인을 초기 설계안으로 검토한다. 3시간 주기로 60분 발견을 보장하지 않는다. 마감 7일 이내, 금액·자격 변경, 안전·돌봄 위험은 검수 우선순위를 높인다. 예약 실행 전에는 수동 실행으로 표시한다.

## 변경 감지 키

현재 구현은 전체 본문 해시와 앞 5,000자 발췌 비교이며 조건별 변경 판별은 미구현이다. 메뉴 변경도 원문 변경으로 감지될 수 있다. 향후 공고 ID·공식 URL·모집 회차로 구분하고 제목, 기간, 대상, 가치, 신청 경로·서류 필드를 비교한다. 변경 사유 검수 전 자격 변경·고객 재판정 완료로 표시하지 않는다. 상세 장애·검수 기준은 [public-notice-operations.md](public-notice-operations.md)를 따른다.
