# 아하루프 콘텐츠 수집

> 현재 뉴스 기반 제품 실험은 레거시다. 혜택 수집·자격 판정·신청 진행에는 `.agents/skills/ahaloop-benefit-recovery/SKILL.md`를 사용한다.

## 목적과 범위

초기 고객군인 스타트업의 사업개발·전략 담당자에게 필요한 AI, B2B SaaS, 고객 경험 자료를 수집한다. 결과는 `한 주의 정보 흐름에서 나에게 필요한 맥락과 다음 행동만 이어 붙인 개인화 묶음`이라는 아하루프의 브리프 정의에 맞게 정리한다.

현재는 파일럿이다. 모든 자료는 운영자가 원문, 날짜, 마감, 요약과 개인화 이유를 확인한 뒤에만 승인한다. 자동 발송하지 않는다.

## 출처 우선순위

1. 기관·기업·학회·채용 플랫폼의 공식 원문, 공식 API 또는 RSS
2. DOI와 출판사 원문처럼 식별자와 발행일을 확인할 수 있는 학술 자료
3. 신뢰할 수 있는 보도 매체의 원문

검색 결과 페이지, 재배포 글, 출처를 확인할 수 없는 요약문만으로 카드를 만들지 않는다. 본문 전체를 저장하지 않고 사실 중심의 짧은 요약과 링크만 보존한다.

파일럿 기본 수집원은 다음과 같다.

- 뉴스: 기업 공식 뉴스룸·블로그와 검증된 매체 원문
- 행사·공모전·지원사업: K-Startup 공식 공고
- 참고 자료: 정부·공공기관·표준기관의 공식 배포 자료
- 학술 자료: Crossref 메타데이터와 출판사 원문
- 채용·기회: 고용24 공식 검색·공고

## 수집 절차

1. 최상위 `작업일지.md`와 `docs/AHALOOP_Content_Automation_Decision_v0.1.md`의 최신 결정을 확인한다.
2. 현재 날짜를 기준으로 공식 원문을 열어 제목, 출처, canonical URL, 게시일, 마감일, 대상 조건과 상태를 확인한다.
3. URL, 공식 공고 ID 또는 DOI를 중복키로 사용한다. 같은 사건을 다룬 여러 글은 원 출처 하나를 우선한다.
4. 다음 필드로 정규화한다: `id`, `type`, `title`, `summary`, `why`, `source`, `sourceUrl`, `publishedAt`, `deadline`, `topics`, `roles`.
5. `title`은 과장 없이 사실을 말하고, `summary`는 무엇인지, `why`는 선택한 관심사·역할에 왜 중요한지를 분리한다.
6. 마감이 지난 모집·채용은 신규 브리프 후보에서 제외한다. 수시·실시간 검색은 그 상태를 명시한다.
7. `lib/content-catalog.ts` 또는 수집 파이프라인의 검수 대기 저장소를 갱신한다. 기존 ID의 원문이 갱신됐으면 새 날짜와 변경 근거를 남긴다.
8. 광고·스폰서 항목은 편집 콘텐츠와 별도 타입·영역으로 유지하고 추천 순위나 평가 보상에 섞지 않는다.

## 검수 기준

- 원문 링크가 열리고 카드의 핵심 사실을 직접 뒷받침한다.
- 게시일과 마감일은 원문 표기와 일치하며 모호한 시간대는 단정하지 않는다.
- 지원 대상, 지역, 비용, 자격과 채용 조건을 추측하지 않는다.
- 학술 초록과 이미지 등 저작물은 허용 범위를 넘게 복제하지 않는다.
- `why`는 투자·합격·성과를 보장하지 않고 다음 검토 행동을 제시한다.
- 카드가 사용자의 선택한 정보 유형과 최소 하나의 관심 분야 또는 역할에 맞는다.

## 완료 확인

- 소스 링크와 API 응답을 실제로 확인한다.
- `npm run build`를 실행한다.
- 관심 설정 변경 후 3~5개의 실제 카드가 필터링되는지 확인한다.
- 각 `원문 확인`이 새 탭을 열고 `open_source` 이벤트를 남기는지 확인한다.
- `오호` 추가 뉴스와 광고가 편집 카드와 구분되는지 확인한다.
- 수집 날짜, 항목 수, 출처, 제외 사유, 빌드·화면 검증 결과를 `작업일지.md`에 덧붙인다.

## 자동화 전환

공식 API 키가 준비되면 출처별 어댑터를 분리하고 `수집 → 정규화 → 중복 제거 → 검수 대기`까지만 예약 실행한다. 파일럿 주기는 뉴스·공고 하루 2회 이하, 채용 6시간, 학술 하루 1회다. 승인과 발송은 계속 분리한다. 출처가 5개를 넘거나 하루 후보가 1,000건을 넘으면 Queue를 도입한다.
