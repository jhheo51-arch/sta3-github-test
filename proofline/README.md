# PROOFLINE v11 · 경험에서 첫 제안으로

자신의 고민과 실제 경험을 정리해 방향 카드 초안을 만들고, 작은 제안을 직접 알린 뒤 반응과 다음 수정을 기록하는 웹 시제품입니다.

## 실행
Node.js 22 이상에서 `npm test`로 기능 검증을 실행합니다. 별도 패키지 설치나 API 키는 필요하지 않습니다.

화면은 이 폴더에서 `python -m http.server 4185 --bind 127.0.0.1 --directory dist`를 실행하고 http://127.0.0.1:4185/ 에 접속하면 확인할 수 있습니다.

## 주요 흐름
- ‘나 혼자 체험’에서 고민·경험·강점·도울 사람·작은 활동을 입력해 방향 카드 초안을 만듭니다.
- 카드와 첫 제안 문구를 수정하고 실제 실행과 반응을 기록합니다.
- ‘가상 사례 보기’에서 가상 박다은의 시연을 확인합니다.
- 동의를 확인한 실제 상담 후보와 개인 체험·가상 사례를 구분합니다. 개인 체험과 가상 사례는 실제 시범 고객 수에 포함하지 않습니다.

개인 체험 초안은 입력한 표현을 정리하는 기능이며 AI의 강점 판정이나 수요 검증이 아닙니다. 외부 모집·메시지 발송·실제 고객 상담·성과 검증은 이 코드가 대신 수행하지 않습니다. 자료는 해당 브라우저에 저장되며 다른 주소의 저장 내용과 자동 공유되지 않습니다. 개인 백업과 연락처는 저장소에 포함하지 않습니다.

## 소스와 검증 범위
로컬 최신 `proofline-2026-10-01-v11/dist`의 화면·스크립트·스타일을 가져왔습니다. 비공개 배포 설정과 개인 상담 자료는 제외했습니다. 기존 검증 파일의 이전 버전 스타일 비교를 독립 실행할 수 있도록 시험용 기준 스타일을 함께 보관했습니다. 개인 체험, 가상 사례, 동의 없는 후보 차단, 제안·반응 기록, 미래 실행 저장 차단을 시험합니다. 브라우저 모양과 실제 사용자 경험은 별도 확인이 필요합니다.
