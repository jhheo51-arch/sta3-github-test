# Fast research execution

Use this as the default execution strategy. Speed comes from batching and early triage, not from weakening verification.

## Fast path

1. Calculate the 7-day range once and generate a compact Korean/English query matrix.
2. Run independent searches in the fewest supported batched calls. Search industry, role, and conference tracks together when possible.
3. Triage results using title, date, publisher, snippet, profile relevance, and likely evidence depth. Keep roughly 8–12 candidates plus at most three backups.
4. Deduplicate obvious repeated events before opening full pages. Reuse already verified URLs and source notes from the current or prior edition when unchanged.
5. Open independent shortlisted sources concurrently. Do not reopen the same page unless a missing fact materially affects ranking or interpretation.
6. Reject stale, inaccessible, duplicate, or thin candidates early. Fully verify only likely highlights and the additional items that will be delivered.
7. Draft overview and detail sections from one structured fact set so the same evidence is not summarized twice from scratch.

## Quality safeguards

- Never infer a date or claim from a search snippet when the original source is available.
- Do not replace independent corroboration with a faster vendor-only claim.
- If the fast path yields fewer than five strong items, deliver fewer items or expand to 30 days and disclose it.
- Report only material access or evidence limitations; do not expose routine research notes.

## Reuse between editions

When a previous edition exists, load its URLs and event names first. Exclude exact duplicates early, then inspect only meaningful follow-ups, changed claims, new recordings, or new job-posting patterns.
