# MEMOIVE v22 안정성과 모바일 검사

검사일: 2026-10-03. 모든 시험 자료는 가상 자료입니다. 실제 고객·제작자의 활용 효과로 집계하거나 발표하지 않습니다.

## 자동 검사

Node에서 아래 다섯 파일을 실행해 통과했습니다.

- `node tests/submission-self-check.cjs`
- `node tests/cases-use-check.cjs`
- `node tests/navigation-order-check.cjs`
- `node tests/before-after-check.cjs` (Site 소스 저장소의 기존 기준 커밋 비교)
- `node tests/storage-safety-check.cjs`

신규 저장 안전성 8개: 보조 보관본 저장 실패 시 주 저장 성공, 용량 실패 시 이전 바이트 보존, 다른 탭의 변경 덮어쓰기 차단, 손상된 주 저장본과 정상 보관본 읽기 전용 복구, 저장 접근 차단 안내, 일부 잘못된 백업의 전체 거부, 12,000자 글과 501개 결과물 보존, 같은 ID의 이전 결과물로 현재 글을 덮어쓰지 않기.

프로그램 문법과 Git 변경 형식도 확인했습니다. 실패 상황을 만든 가상 저장 장치 검사이며 실제 모바일 저장 용량을 가득 채운 시험은 아닙니다.

## 브라우저 화면 검사

로컬의 분리된 주소에서 진행했고 운영 사이트의 개인 기록을 사용하지 않았습니다.

| 조건 | 확인 결과 |
| --- | --- |
| 375×812 | 텍스트와 생각 저장, 생각의 단어 검색 결과 1건, 결과물 기본 초안 생성·직접 편집·저장 |
| 320×568 | 결과물 본문 편집·닫기 취소·저장·새로고침·재열기 후 문장 유지, 문서 가로 넘침 없음 |
| 667×375 | 가로 화면에서 본문 입력 영역에 접근, 문서 가로 넘침 없음 |
| 키보드 | 기록 입력창의 첫 항목에서 Shift+Tab으로 마지막 저장 버튼, Tab으로 처음 복귀, Escape 상세 닫기, 배경 화면은 열린 창 뒤에서 조작 대상 제외 |
| 글 교체 | 초안 다시 만들기에서 화면 안 확인 후 ‘지금 글 유지’ 선택 시 기존 편집 문장 유지 |
| 두 탭 | 다른 탭에서 관점 저장 후 이전 탭의 결과물 저장을 시도하면 충돌 안내, 결과물 입력 필드 보존, 저장 성공 문구 없음 |

현재 구현은 아직 모바일 네이티브 앱이 아닙니다. 위 검사는 브라우저 화면 크기 조절 시험입니다. 실제 iOS·Android 단말의 화면 키보드·음성·공유·설치, 화면 읽기 도구, OS 글자 확대와 200% 확대의 전수 검증은 수행하지 않았습니다.

## 복구 안내와 남은 한계

저장 실패 시 기록 상태는 마지막 성공 상태로 돌아가며 편집 필드는 유지됩니다. 충돌 경고가 있으면 입력한 글을 따로 복사한 뒤 새로고침합니다. 임시 입력이 새로고침 후 자동 복원되는 기능은 없습니다.

현재 보관은 기기·브라우저 안입니다. 브라우저 데이터 삭제·분실·저장 장치 장애를 막는 서버 보관이나 자동 동기화는 구현하지 않았습니다. 매우 동시에 실행되는 두 탭 사이의 완전한 거래 보장은 없으며 서버 버전 충돌 관리가 후속 과제입니다.

손상된 기본 저장본은 자동 덮어쓰지 않습니다. 읽을 수 있는 보관본을 백업해 별도 브라우저에서 가져올 수 있으며, 둘 다 읽을 수 없으면 기존 외부 백업이 필요합니다. 암호화 백업이나 손상 파일 자동 수리는 제공하지 않습니다.

백업은 10MB 이내 가져오기를 지원합니다. 기록과 결과물은 조용히 자르지 않지만 사용 이벤트는 기존대로 최근 2,000개만 보존합니다. 같은 ID의 결과물은 현재 버전을 우선하며 백업 파일의 글을 자동으로 덮어쓰지 않습니다.

이미지·음성은 확인한 문장만 기록으로 저장합니다. 이미지 원본·녹음 파일 영구 보관, 실제 모든 기기의 문자·음성 인식 성공은 미검증입니다. 마이크 해제 코드는 보완했지만 이번에 실제 마이크 권한을 승인하거나 녹음하지 않았습니다.

## 배포와 제출

같은 소유자 전용 Site에 게시하며 접근 대상을 넓히지 않습니다. 개인 기록·백업·API 키·브라우저 저장 자료는 GitHub나 배포 묶음에 넣지 않습니다. 연구 문서의 외부 링크는 공개 자료이며 개인 시험 결과를 포함하지 않습니다.

수요 검토는 별도 [탐색 보고서](demand-differentiation-2026-10-03-v01.md)를 참고합니다. 실제 활용 효과는 사용자가 앞으로 진행하며 이 문서에는 완료로 기재하지 않습니다.
