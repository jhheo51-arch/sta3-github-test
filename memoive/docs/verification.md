# MEMOIVE 기술 점검 범위

2026년 10월 1일, 제출 준비 버전에서 수행한 기술 점검입니다. AI가 입력한 가상 시험 자료를 사용했으며 제작자 본인이나 외부 사용자의 실사용 결과가 아닙니다. 실사용 만족도·수요·시간 단축은 아직 확인하지 않았습니다.

## 실제 화면에서 확인한 흐름

Chrome의 375 × 812 화면 크기에서 다음을 수행했습니다.

1. 기술 점검용 텍스트와 ‘온보딩에서 첫 결과물을 보여주는 실험’이라는 생각을 함께 저장했습니다.
2. 상세를 닫고 ‘온보딩 실험’으로 검색했을 때 해당 기록 1개가 나왔습니다.
3. 해당 기록의 결과물 만들기에서 기존 생각이 관점에 전달되는 것을 확인했습니다.
4. 업무 제안서 기본 초안을 만들고 제목·본문을 직접 바꿔 저장했습니다.
5. 새로고침 후 창작 메뉴에서 편집한 결과물과 연결된 참고 내용·내 생각을 다시 확인했습니다.
6. 분석 화면에서 예시 5개를 제외하고 시험용 직접 입력 기록 1개만 계산하는 것을 확인했습니다.
7. 사용 테스트 타이머를 시작하고 새로고침한 뒤에도 측정 중 상태와 환경·버전이 유지되는 것을 확인했습니다.
8. 별도 로컬 시험에서 중단 회차를 저장한 뒤 새로고침해 복원하고, 다음 회차에 연결해 이전 문제·변경·전후 결과가 표시되는 것을 확인했습니다. 이 회차들은 실사용이 아닌 AI 기능 시험으로 표시했습니다.

로컬 브라우저의 시험 데이터는 운영 Site나 제출용 근거 파일로 복사하지 않았습니다. 이 목록은 확인한 기술 범위만 뜻하며 모든 입력 형식·기기를 검증한 것은 아닙니다.

## 발견한 문제와 변경 전후

비교 기준은 이전 Site 소스 커밋 `990d77e00f1f0faee4a2c1c6fb6f7fce79681af5`입니다. 다음 수치는 의도적으로 만든 고정 시험 자료의 결과이지 사용자 지표가 아닙니다.

| 발견한 문제 | 바꾼 점 | 같은 자료로 재시험 |
| --- | --- | --- |
| 핵심 문장에만 있는 단어는 검색되지 않음 | 핵심 문장·근거·주소까지 검색, 여러 검색어를 함께 확인 | 검색 결과 0개에서 목표 기록 1개로 변경 |
| 기본 예시까지 실제 사용 분석에 포함 | 기본 예시 5개를 분모에서 제외, 존재하지 않는 기록의 열람도 제외 | 예시 5개와 직접 입력 1개로 총 6개였던 집계가 1개로 변경 |
| SNS 초안의 ‘기록에서 확인한 것’에 개인 생각을 넣음 | 출처 요약을 참고 영역에, 개인 의견은 관점 영역에 배치 | 원문 영역에 개인 의견이 대신 들어가지 않는지 확인 |
| 연결 전인데 Gemini 버튼으로 노출 | 연결 상태에 맞는 기본 초안 버튼과 안내 | 연결 전 화면에서 기본 초안 버튼 확인 |
| 근거 없는 정확도처럼 보이는 퍼센트 | 검증되지 않은 신뢰 퍼센트를 화면에서 제거 | 상세에 원문 확인 권장 안내 표시 |
| 닫힌 입력 패널도 접근성 목록에 노출 | 닫힌 패널을 시각·접근성 트리에서 숨김 | 새로고침 후 닫힌 패널 목록이 노출되지 않음 |

## 자동 점검 재현

저장소의 `memoive` 폴더에서 실행합니다.

```sh
node --check app.js
node --check self-test.js
node tests/submission-self-check.cjs
node tests/before-after-check.cjs
```

검색의 비변경성, 예시 제외, 출처와 의견 구분, 과제·방식·버전별 테스트 집계, 잘못된 백업 거절, 중복 병합 시 기존 기록 보존, 표 내보내기의 수식 해석 방지를 확인했습니다. 공개 저장소의 `before-after-check.cjs`에는 비교 기준 커밋에서 읽은 이전 계산·검색 코드를 포함했습니다. 별도 비공개 Git 이력이나 API 키 없이 같은 고정 자료의 변경 전후를 재현합니다. 이는 기술 회귀 검사이며 실제 사용자의 개선 성과가 아닙니다.

## 아직 확인하지 않은 것

- 제작자 본인의 실제 반복 사용과 개선 후 체감, 외부 사용자의 최초 사용성.
- 실물 휴대폰의 터치·마이크·공유 메뉴, 화면 읽기 도구의 전체 탐색.
- 이번 변경에서 공개 기사 읽기의 외부 서비스 응답, 로그인·유료·유튜브 본문 수집.
- 외부 AI의 실제 응답과 요약 품질, Cloudflare 운영 설정과 프로젝트별 무료 한도.
- 브라우저 저장 공간 부족·모든 가져오기 실패·실제 장기 사용 상황.

이 한계 때문에 제품 완성·검증 완료·고객 가치 입증이라고 표현하지 않습니다.

## v15 추가 기술 점검 (2026-10-01)

- 사례 3개 추가 시 기존 ID·같은 주소의 기록과 사용자 생각을 보존하고 중복으로 늘리지 않는지 자동 검사했습니다.
- 예시만 참조한 결과물, 활용 근거가 없는 결과물은 실제 활용 집계에서 제외합니다. 새 활용 필드의 백업 왕복과 이전 형식 불러오기를 검사했습니다.
- 375 × 812 브라우저에서 세 사례를 선택한 개선 제안서 예시 열기·저장, 사례에서 연결 결과물 이어 쓰기, 직접 기록의 생각 전달·초안 생성·활용 근거 저장을 확인했습니다.
- 사용 체크만 하고 근거를 비우면 입력 안내와 해당 입력란으로 이동합니다. 체크하지 않은 일반 결과물 저장은 허용합니다.
- 예시 결과물을 사용했다고 표시해도 집계 0, 직접 입력한 시험 기록의 활용 근거 저장 후 1, 새로고침 뒤 유지, 체크 취소 후 0을 확인했습니다. 이 숫자는 AI 기능 시험 자료이지 실제 사용 성과가 아닙니다.
- 브라우저 375픽셀 세로·812픽셀 가로에서 문서 가로 넘침이 없었습니다. 실물 휴대폰·보조기기 전체 탐색·텍스트 최대 확대는 별도 확인이 필요합니다.
- 화면 자산 버전 표기를 추가해 새 HTML과 이전 JavaScript가 섞이는 현상을 방지했습니다. 기존 저장 키와 보관된 기록은 변경하지 않았습니다.
- 시험 자료는 로컬 주소에서만 입력했으며 운영 Site로 옮기지 않습니다. 외부 생성형 AI는 여전히 미연결입니다.

## v16 메뉴·최신순 기술 점검 (2026-10-01)

- 날짜 내림차순, 같은 날의 저장 시각 비교, 시각 없는 이전 기록의 동일 날짜 내 기존 순서, 잘못된 시각의 안전한 처리, 백업 왕복과 원본 불변 자동 검사를 통과했습니다.
- 로컬 브라우저에서 시험 A 저장 후 B 저장, 새로고침 후 B → A 표시를 확인했습니다. 홈과 달력도 같은 순서였으며 이전 기록·생각이 유지됐습니다. 이는 기술 시험이지 실제 사용자 활용 성과가 아닙니다.
