# Todo App PRD

## 제품 목적
사용자가 해야 할 일을 빠르게 기록하고, 현재 해야 할 일에 집중할 수 있도록 돕는 간단한 Todo 앱입니다.

## 주요 사용자
복잡한 설정 없이 개인 할 일을 간단하게 관리하고 싶은 사용자입니다.

## 현재 핵심 기능
- 할 일 추가
- 완료/미완료 전환
- 할 일 삭제
- 브라우저에 할 일 저장
- 남은 할 일 개수 확인

## 제품 원칙
- 사용법을 따로 배우지 않아도 될 만큼 단순하게 유지합니다.
- 새로운 기능을 추가할 때 기존 핵심 기능을 깨뜨리지 않습니다.
- 한 번에 너무 많은 기능을 추가하지 않습니다.
- 사용자가 해야 할 일을 더 쉽게 찾고 관리하도록 개선합니다.

## 향후 개선 방향
할 일이 많아졌을 때도 중요한 일을 구분하고, 필요한 일을 빠르게 찾고, 일정에 맞춰 관리할 수 있도록 점진적으로 개선합니다.
