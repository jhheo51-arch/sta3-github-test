# Todo App — Git Branch & Worktree 실습

수업용으로 준비된 작은 Todo 앱입니다.

## 현재 구현된 기능
- 할 일 추가
- 완료/미완료 전환
- 삭제
- localStorage 저장
- 남은 할 일 개수 표시

## 실습 시작 상태
- `docs/PRD.md`: 제품의 목적과 원칙이 정의되어 있습니다.
- `AGENTS.md`: AI Agent가 프로젝트에서 작업할 때 지킬 원칙이 정의되어 있습니다.
- `specs/`: 비어 있습니다. 기능 구현 전에 학생이 Codex와 함께 기능 명세를 작성합니다.

권장 실습 흐름:
1. 우선순위 기능의 Spec 작성
2. 새 Branch에서 우선순위 기능 구현 및 검증
3. 검색 기능과 마감일 기능의 Spec 작성
4. 두 기능을 위한 Branch + Worktree 생성
5. 두 Codex 세션에서 병렬 구현 및 검증
