# 전체 완료 축하 안내 기능 명세

## 1. 목적

사용자가 선택한 날짜에 등록된 할 일을 모두 완료했을 때 성취를 분명하고 기분 좋게 확인할 수 있게 합니다.

## 2. 기능 범위

### 표시 조건

- 선택한 날짜에 Todo가 한 개 이상 있고 모든 Todo가 완료되었을 때만 축하 안내를 표시합니다.
- 선택한 날짜에 미완료 Todo가 하나라도 있거나 Todo가 하나도 없으면 안내를 표시하지 않습니다.
- 완료 항목을 다시 미완료로 바꾸거나 새 Todo를 추가하면 안내를 숨깁니다.

### 축하 안내

- 목록 아래에 `모든 할 일을 완료했어요!`라는 축하 문구를 표시합니다.
- 완료를 나타내는 짧은 라벨과 성취를 응원하는 문장을 함께 표시합니다.
- 은은한 배경과 장식 요소로 축하 영역을 다른 목록 내용과 구분합니다.
- 추가 할 일이 있는지 묻는 질문이나 별도의 행동 버튼은 표시하지 않습니다.

### 접근성

- 축하 안내가 새로 표시될 때 화면 읽기 프로그램이 내용을 자연스럽게 알 수 있도록 하나의 상태 영역으로 제공합니다.
- 안내는 색상에만 의존하지 않고 문구로 완료 상태를 전달합니다.
- 시각적 장식은 화면 읽기 프로그램의 읽기 순서에 포함하지 않습니다.

## 3. 기존 기능 유지

- 할 일 추가
- 완료/미완료 전환
- 할 일 삭제
- 브라우저 저장 및 새로고침 후 복원
- 남은 할 일 개수 표시
- 할 일이 없을 때 빈 상태 표시

## 4. 완료 조건

- [x] 선택한 날짜에 Todo가 한 개 이상이고 모두 완료되면 꾸며진 축하 안내가 표시된다.
- [x] 축하 안내에 완료 라벨, 축하 제목, 응원 문장이 표시된다.
- [x] 추가 할 일이 있는지 묻는 질문이나 행동 버튼이 표시되지 않는다.
- [x] 미완료 Todo가 있거나 Todo가 없으면 축하 안내가 표시되지 않는다.
- [x] 완료 항목을 미완료로 바꾸거나 새 Todo를 추가하면 축하 안내가 사라진다.
- [x] 축하 안내가 하나의 접근 가능한 상태 영역으로 제공된다.
- [x] 기존 추가, 완료 전환, 삭제, 저장, 남은 개수, 빈 상태 기능이 정상 동작한다.
- [x] 데스크톱과 375px 모바일 화면에서 컨트롤이 겹치거나 가로로 잘리지 않는다.
- [x] 브라우저 콘솔에 오류가 발생하지 않는다.

## 5. 이번 범위에서 제외

- 팝업 또는 모달 축하 화면
- 소리, 진동, 색종이 애니메이션
- 새 Todo 추가를 유도하는 질문 또는 행동 버튼
- 연속 완료 기록과 보상 시스템
- 축하 문구 사용자 설정
- 외부 공유 기능
