# Todo 검색 기능 명세

## 1. 목적

사용자가 Todo가 많아져도 제목에 포함된 단어로 필요한 할 일을 빠르게 찾을 수 있게 합니다.

## 2. 기능 범위

### 검색창

- Todo 목록을 검색하기 위한 검색창 하나를 제공합니다.
- 검색 대상은 Todo 제목입니다.
- 검색은 영문 대소문자를 구분하지 않습니다.

### 목록 필터링

- 사용자가 검색어를 입력하면 별도의 제출 동작 없이 즉시 제목이 일치하는 Todo만 표시합니다.
- Todo 제목에 검색어가 일부라도 포함되면 일치하는 항목으로 표시합니다.
- 검색어를 모두 지우면 전체 Todo 목록을 다시 표시합니다.
- 검색은 화면에 표시되는 목록만 필터링하며 Todo 데이터와 저장된 내용은 변경하지 않습니다.

## 3. 기존 기능 유지

검색 중에도 다음 기능은 기존과 동일하게 동작해야 합니다.

- 할 일 추가
- 완료/미완료 전환
- 할 일 삭제
- 브라우저 저장 및 새로고침 후 복원
- 남은 할 일 개수 표시

## 4. 완료 조건

- [x] Todo 제목을 검색할 수 있는 검색창 하나가 표시된다.
- [x] 검색어를 입력하는 즉시 제목에 검색어가 포함된 Todo만 표시된다.
- [x] 영문 대소문자가 달라도 같은 검색 결과가 표시된다.
- [x] 검색어를 모두 지우면 전체 Todo 목록이 표시된다.
- [x] 검색으로 숨겨진 Todo가 삭제되거나 저장 데이터에서 변경되지 않는다.
- [x] 검색 중에도 기존 추가, 완료 전환, 삭제, 저장, 남은 개수 기능이 정상 동작한다.

## 5. 이번 범위에서 제외

- Todo 내용 또는 메모 검색
- 완료 여부, 우선순위, 날짜 등 조건별 필터링
- 검색어 자동 완성 및 최근 검색어 저장
- 검색 결과 정렬
- 검색어 강조 표시
