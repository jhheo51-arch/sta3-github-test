# Todo 우선순위 기능 명세

## 1. 목적

사용자가 각 할 일의 중요도를 간단히 구분하고, 목록에서 중요한 일을 빠르게 알아볼 수 있게 합니다.

## 2. 사용자 이야기

사용자는 할 일을 추가할 때 우선순위를 정하고, 필요하면 나중에 바꿀 수 있습니다. 목록에서는 각 할 일의 우선순위를 한눈에 확인할 수 있습니다.

## 3. 기능 범위

### 우선순위 단계

- 높음
- 보통
- 낮음

새 할 일의 기본 우선순위는 `보통`입니다.

### 할 일 추가

- 할 일 입력 영역에서 우선순위를 선택할 수 있습니다.
- 우선순위를 따로 선택하지 않으면 `보통`으로 추가합니다.
- 빈 제목의 할 일은 기존과 동일하게 추가하지 않습니다.

### 목록 표시 및 변경

- 각 할 일에 현재 우선순위를 글자로 표시합니다.
- 사용자는 목록에서 기존 할 일의 우선순위를 변경할 수 있습니다.
- 우선순위를 변경해도 완료 여부와 목록 순서는 바뀌지 않습니다.

### 저장

- 각 Todo 데이터에 `priority` 값을 저장합니다.
- 저장 값은 `high`, `medium`, `low` 중 하나입니다.
- 이전 버전에서 저장되어 `priority`가 없는 할 일은 `medium`으로 취급합니다.
- 추가, 완료/미완료 전환, 삭제 및 우선순위 변경 뒤에도 전체 목록을 브라우저 저장소에 저장합니다.

## 4. 화면 및 사용성 요구사항

- 우선순위는 색상만으로 구분하지 않고 `높음`, `보통`, `낮음`이라는 글자를 함께 표시합니다.
- 키보드와 화면 읽기 프로그램으로 우선순위를 선택하고 변경할 수 있어야 합니다.
- 작은 화면에서도 제목, 완료 체크박스, 우선순위, 삭제 버튼을 사용할 수 있어야 합니다.
- 기존의 단순한 한 화면 구조를 유지합니다.

## 5. 기존 기능 유지

다음 기능은 현재와 동일하게 동작해야 합니다.

- 할 일 추가
- 완료/미완료 전환
- 할 일 삭제
- 브라우저 저장 및 새로고침 후 복원
- 남은 할 일 개수 표시
- 할 일이 없을 때 빈 상태 표시

## 6. 완료 조건

- [x] 사용자가 새 할 일에 `높음`, `보통`, `낮음` 중 하나를 선택할 수 있다.
- [x] 우선순위를 선택하지 않은 새 할 일은 `보통`으로 추가된다.
- [x] 각 할 일에서 현재 우선순위를 글자로 확인할 수 있다.
- [x] 기존 할 일의 우선순위를 변경할 수 있다.
- [x] 우선순위 변경 후 새로고침해도 선택한 값이 유지된다.
- [x] `priority`가 없는 기존 저장 데이터도 오류 없이 `보통`으로 표시된다.
- [x] 우선순위를 변경해도 완료 상태와 목록 순서가 유지된다.
- [x] 기존의 추가, 완료 전환, 삭제, 저장, 남은 개수 기능이 정상 동작한다.
- [x] 데스크톱과 모바일 화면에서 컨트롤이 겹치거나 잘리지 않는다.
- [x] 브라우저 콘솔에 오류가 발생하지 않는다.

## 7. 이번 범위에서 제외

- 우선순위에 따른 자동 정렬
- 우선순위별 필터링 또는 검색
- 사용자 정의 우선순위 단계
- 마감일, 알림, 반복 Todo
- 여러 기기 간 동기화
