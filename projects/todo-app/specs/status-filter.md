# Todo 완료 상태 필터 기능 명세

## 1. 목적

사용자가 현재 목록에서 전체 Todo, 진행 중인 Todo, 완료한 Todo를 간단히 구분해 볼 수 있게 합니다.

## 2. 기능 범위

### 필터 선택

- 목록에 `전체`, `진행 중`, `완료` 세 가지 필터를 제공합니다.
- 앱을 처음 열거나 새로고침했을 때 기본 필터는 `전체`입니다.
- 한 번에 하나의 필터만 선택할 수 있습니다.
- 사용자가 필터를 선택하면 목록을 즉시 갱신합니다.

### 필터별 표시 기준

- `전체`는 현재 목록의 완료 및 미완료 Todo를 모두 표시합니다.
- `진행 중`은 완료되지 않은 Todo만 표시합니다.
- `완료`는 완료된 Todo만 표시합니다.
- 필터는 Todo의 표시 여부만 바꾸며 Todo 데이터, 완료 상태, 저장 내용, 목록 순서는 변경하지 않습니다.
- 현재 날짜가 선택된 구조에서는 선택한 날짜의 Todo에만 상태 필터를 적용합니다.

### 필터 결과가 없을 때

- 선택한 필터에 해당하는 Todo가 없으면 결과가 없음을 알리는 짧은 문구를 표시합니다.
- 다른 필터를 선택하면 해당 조건에 맞는 Todo를 다시 표시합니다.

## 3. 화면 및 접근성 요구사항

- 현재 선택된 필터를 글자와 시각적 강조로 구분합니다.
- 필터는 키보드로 이동하고 선택할 수 있어야 합니다.
- 화면 읽기 프로그램이 각 필터의 이름과 현재 선택 상태를 확인할 수 있어야 합니다.
- 데스크톱과 375px 모바일 화면에서 필터가 겹치거나 가로로 잘리지 않아야 합니다.
- 기존 앱의 단순한 한 화면 구조와 시각적 분위기를 유지합니다.

## 4. 기존 기능 유지

- 필터가 적용된 상태에서도 표시된 Todo의 완료/미완료 전환과 삭제가 정상 동작해야 합니다.
- 할 일 추가와 브라우저 저장 및 새로고침 후 복원이 기존과 동일하게 동작해야 합니다.
- 남은 할 일 개수는 선택한 상태 필터와 관계없이 현재 선택한 날짜의 전체 미완료 Todo를 기준으로 표시합니다.
- Todo를 추가하거나 완료 상태를 바꾸거나 삭제하면 현재 필터 조건에 맞춰 목록을 즉시 다시 표시합니다.

## 5. 완료 조건

- [x] 처음 열거나 새로고침했을 때 `전체` 필터가 선택된다.
- [x] `전체`를 선택하면 완료 여부와 관계없이 현재 목록의 모든 Todo가 표시된다.
- [x] `진행 중`을 선택하면 미완료 Todo만 표시된다.
- [x] `완료`를 선택하면 완료 Todo만 표시된다.
- [x] 필터를 바꿔도 Todo 데이터, 완료 상태, 저장 내용, 목록 순서가 변경되지 않는다.
- [x] 선택한 필터에 해당하는 Todo가 없으면 결과 없음 문구가 표시된다.
- [x] 필터 적용 상태에서 Todo 추가, 완료/미완료 전환, 삭제, 저장 및 복원이 정상 동작한다.
- [x] 남은 할 일 개수는 필터와 관계없이 현재 선택한 날짜의 전체 미완료 Todo 수를 표시한다.
- [x] 키보드와 화면 읽기 프로그램으로 필터를 선택하고 현재 선택 상태를 확인할 수 있다.
- [x] 데스크톱과 375px 모바일 화면에서 필터가 겹치거나 가로로 잘리지 않는다.
- [x] 브라우저 콘솔에 오류가 발생하지 않는다.

## 6. 이번 범위에서 제외

- 필터 선택 상태 저장
- 우선순위, 날짜 또는 검색어와 결합한 새로운 복합 필터 UI
- 사용자 정의 필터
- 필터별 Todo 개수 배지
- 정렬 방식 변경
