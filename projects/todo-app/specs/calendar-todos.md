# 날짜별 Todo 달력 기능 명세

## 1. 목적

사용자가 달력에서 날짜를 선택해 해당 날짜의 할 일을 확인하고 추가할 수 있게 합니다.

## 2. 기능 범위

### 달력

- 한 달 단위의 달력을 표시합니다.
- 처음 열었을 때 오늘 날짜와 오늘이 포함된 달을 선택합니다.
- 이전 달과 다음 달로 이동할 수 있습니다.
- 날짜를 선택하면 선택 상태를 글자와 시각적 강조로 확인할 수 있습니다.
- 할 일이 있는 날짜에는 해당 날짜의 전체 할 일 개수를 표시합니다.

### 날짜별 목록

- 목록에는 선택한 날짜의 할 일만 표시합니다.
- 선택한 날짜를 한국어 형식의 제목으로 표시합니다.
- 선택한 날짜에 할 일이 없으면 기존 빈 상태 문구를 표시합니다.
- 남은 할 일 개수는 선택한 날짜의 미완료 항목을 기준으로 표시합니다.

### 할 일 추가 및 저장

- 할 일 추가 영역에 날짜 입력을 제공합니다.
- 날짜 입력의 기본값은 현재 선택한 날짜입니다.
- 달력에서 날짜를 선택하면 날짜 입력도 같은 날짜로 변경합니다.
- 새 할 일에는 `date` 값을 `YYYY-MM-DD` 형식으로 저장합니다.
- 이전 버전에서 저장되어 `date`가 없는 할 일은 처음 불러온 날의 오늘 날짜로 취급합니다.
- 날짜별 정보도 기존 Todo 목록과 함께 브라우저 저장소에 저장합니다.

## 3. 기존 기능 유지

- 할 일 추가
- 완료/미완료 전환
- 할 일 삭제
- 브라우저 저장 및 새로고침 후 복원
- 선택한 날짜의 남은 할 일 개수 표시
- 선택한 날짜에 할 일이 없을 때 빈 상태 표시

## 4. 화면 및 접근성 요구사항

- 달력의 요일과 날짜를 한국어 사용 환경에 맞게 표시합니다.
- 날짜 버튼은 키보드로 이동하고 선택할 수 있어야 합니다.
- 오늘 날짜와 선택 날짜를 색상만으로 구분하지 않고 접근성 이름과 글자 표시를 함께 제공합니다.
- 데스크톱과 375px 모바일 화면에서 달력과 Todo 컨트롤이 겹치거나 가로로 잘리지 않아야 합니다.
- 기존 앱의 단순한 한 화면 구조와 시각적 분위기를 유지합니다.

## 5. 완료 조건

- [x] 현재 월 달력과 오늘 날짜가 처음에 표시된다.
- [x] 이전 달과 다음 달로 이동할 수 있다.
- [x] 날짜를 선택하면 해당 날짜의 Todo만 표시된다.
- [x] 할 일이 있는 날짜에 Todo 개수가 표시된다.
- [x] 새 할 일에 선택한 날짜가 `YYYY-MM-DD`로 저장된다.
- [x] 날짜가 없는 기존 저장 데이터가 오늘 날짜에서 오류 없이 표시된다.
- [x] 새로고침 후 Todo의 날짜, 완료 상태, 목록 내용이 유지된다.
- [x] 기존 추가, 완료 전환, 삭제, 저장, 남은 개수, 빈 상태 기능이 정상 동작한다.
- [x] 키보드로 월 이동과 날짜 선택을 할 수 있다.
- [x] 데스크톱과 375px 모바일 화면에서 겹침과 가로 스크롤이 없다.
- [x] 브라우저 콘솔에 오류가 발생하지 않는다.

## 6. 이번 범위에서 제외

- 반복 Todo
- 알림과 마감 시간
- 주간 보기와 연간 보기
- 드래그 앤 드롭 일정 이동
- 날짜별 자동 정렬 외의 사용자 정의 정렬
