# AGENTS.md

이 프로젝트에서 작업할 때 다음 원칙을 따릅니다.

1. 작업을 시작하기 전에 `docs/PRD.md`를 확인합니다.
2. 기능을 구현하기 전에 `specs/`에 해당 기능 명세가 있는지 확인합니다.
3. 명세가 없다면 바로 구현하지 말고 먼저 기능 명세를 작성합니다.
4. 명세에 없는 기능을 임의로 크게 확장하지 않습니다.
5. 기존 Todo 추가, 완료, 삭제, 저장 기능을 최대한 유지합니다.
6. 한 번에 하나의 기능에 집중합니다.
7. 구현 후 기능 명세의 완료 조건과 기존 핵심 기능을 직접 확인합니다.
8. Git 작업 시 현재 branch와 변경 상태를 확인하고, 기존 작업을 불필요하게 덮어쓰지 않습니다.
