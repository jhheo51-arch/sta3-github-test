## 3 POINT CONTEST
- 참고 영상: NBA 공식 채널의 FULL 2021 NBA 3-Point Contest (https://www.youtube.com/watch?v=K7shu3XmW4g). 거치대 사이 연속 슛, 위치·공 진행 표시를 참고. 공식 로고·실제 선수 외형은 사용하지 않습니다.
- 사용자가 기존 SHOOTING 유지, 별도 모드 및 장거리 보너스 포함 구성을 선택했습니다.
- 3초 준비 뒤 70초 동안 27개 공, 최대 40점. 5개 위치마다 5개 공, 장거리 2개 공.
- 일반 공 1점, 각 위치의 마지막 공 2점. 사용자가 지정한 머니볼 위치는 5개 모두 2점. 장거리 2개는 각 3점.
- 왼쪽 코너 → 왼쪽 윙 → 왼쪽 장거리 → 정면 → 오른쪽 장거리 → 오른쪽 윙 → 오른쪽 코너 순서.
- Space를 누른 뒤 초록 영역에서 놓기. 위치·거리별 목표 세기와 허용 폭이 달라집니다. 확률형 판정 유지.
- 한 공이 판정되면 다음 공을 공급하고, 위치가 바뀔 때 자동 이동합니다. 수동 이동·리바운드 회수·덩크·연속 성공 보너스는 이 모드에서 적용하지 않습니다.
- 준비·이동·공 비행 중에는 추가 슛을 시작할 수 없습니다. 준비 3초는 70초에 포함하지 않습니다. 이동과 공 비행 시간은 포함합니다.
- 27개 소진 또는 시간 종료 시 결과. 버저 전 놓은 마지막 슛은 시간 종료 후에도 판정합니다. 누른 채 종료된 슛은 발사하지 않습니다. 종료는 한 번만 기록합니다.
- P/Esc·버튼·탭 이탈 일시정지 유지. 정지는 공 비행·자동 이동·준비 시간을 모두 멈춥니다.
- 실제 코트에 공 거치대 5개·남은 공·장거리 지점 표시. 공 진행판 27칸과 현재 위치·머니볼/장거리 색상. 결과에 위치별 득점과 성공률.
- 전용 최고 점수를 공용 D1 랭킹에 누적, 상위 5명 표시. 기존 4개 모드 순위와 분리. 같은 이름 합산·중복 방지 방식 유지. 기존 테이블 변경 없이 contest 모드 추가.

## 헤어스타일
- 기존 삭발·짧은 머리·곱슬·땋은 머리·포니테일·아프로를 개선합니다.
- 테이퍼 페이드·사이드 파트·짧은 트위스트 3종 추가, 총 9종.
- 앞·뒤에 맞는 헤어라인과 목덜미 윤곽, 옆머리 길이 변화, 가르마·곱슬·땋은 결을 구분합니다.
- 포니테일은 머리 뒤에서 그려 얼굴을 가리지 않으며 이동에 따라 흔들립니다. 트위스트 끝에도 작은 흔들림을 적용합니다. 정지하면 정지합니다.

## 1. 풀고자 하는 문제

- **지금은 이렇게 해요:** 복잡한 설치 없이 컴퓨터에서 바로 실행할 수 있는 농구 게임으로, 캐릭터를 꾸민 뒤 AI 1대1·친구 1대1 또는 슈팅 연습을 선택해 플레이합니다.
- **이게 불편해요:** 단순히 슛 게이지만 맞추는 게임은 실제 농구의 변수와 공수 경쟁이 부족합니다. 실패한 공을 주워야 한다는 규칙, 자연스러운 밀착 수비, 스틸 회피 기술과 참여자별 기록 비교도 필요합니다.
- **이렇게 되면 좋겠어요:** 슛 정확도는 성공 확률을 높이되 결과를 확정하지 않고, 백보드·링·에어볼·리바운드·레이업·덩크가 자연스럽게 이어집니다. AI와 공을 빼앗고 지키는 경쟁을 하며, 이름별·모드별 기록도 확인할 수 있습니다.

## 3. 입력 자료

- **사용할 입력 내용:** 선수 이름, FIBA 국가협회, 피부색, 헤어스타일, 헤어밴드, 손목·다리 보호대, 등번호와 키보드 조작
- **반드시 필요한 항목:** 1~16자의 선수 이름과 선택한 캐릭터 설정
- **개인정보나 민감 정보 포함 여부:** 실제 개인정보를 요구하지 않습니다. 이름과 국적은 게임 캐릭터용 값이며 기록은 같은 브라우저 안에 저장됩니다. 온라인 경기에서는 상대에게 게임 이름·외형·국가·주손과 경기 상태를 전달합니다. 접속할 때마다 초기화하지 않으며, 브라우저·기기를 바꾸거나 사이트 데이터를 삭제하면 기존 기록을 볼 수 없습니다.
- **국가 선택:** FIBA 국가협회 212개를 공식 영문명과 3글자 코드로 제공합니다. 대한민국(KOR)이 기본값입니다.

## 4. 핵심 기능 (MVP) : 이것만 되면 일단 성공

1. **캐릭터와 화면 흐름**
   - 최초 접속 로딩 → 캐릭터 설정 → 모드 선택 → 모드 로딩 → 경기 → 결과 순서로 이동합니다.
   - 모드 선택에서 캐릭터를 다시 설정하거나 경기·결과 화면에서 모드 선택으로 돌아갈 수 있습니다.
   - 설정한 이름, 피부색, 머리, 헤어밴드, 손목·다리 보호대와 등번호가 실제 경기 캐릭터에 그대로 적용됩니다.
   - 설정 화면의 유니폼 색은 선택한 국가에 맞춰 바뀌며, 경기에서는 플레이어 파랑·AI 빨강으로 통일합니다.
   - 다리 보호대는 해당 다리의 무릎 아래부터 발목 위까지 실제 다리 선 위에 밀착하며, 관절 움직임과 함께 이동합니다.
   - 걷기는 좌우 다리가 교차하지 않는 교대 발걸음, 발 들기와 착지, 반대 방향 팔 흔들기를 사용합니다. 실제 이동량에 맞춰 재생하고 정지 시 자연스럽게 멈춥니다.
   - 헤어스타일은 두상에 맞는 연속적인 윤곽과 머릿결로 표현합니다. 곱슬·아프로는 작은 컬, 땋은 머리는 두피 곡선을 따르는 머리줄, 포니테일은 머리 뒤 묶음으로 구분합니다.
   - 설정 미리보기와 실제 경기에서 동일한 선수 그리기 함수를 사용합니다.

2. **농구공과 확률형 슛**
   - 공을 소유하고 슛하지 않을 때는 공이 계속 바운드됩니다.
   - 슛 게이지는 `Space`를 누르고 있을 때만 나타납니다.
   - 슈팅 모드는 골대까지의 실제 위치에 따라 목표 세기, 초록·정확 구간 폭과 게이지 속도를 계산합니다. 가까울수록 적은 세기, 멀수록 더 큰 세기가 필요합니다.
   - 현재 거리와 목표 세기를 화면에 표시하며, 슛을 준비하면서 이동하면 구간과 판정도 새 위치에 맞춰 갱신합니다. 1대1의 기존 게이지 판정은 유지합니다.
   - 세기가 크게 부족하거나 넘친 슛의 착지점은 골대 방향과 세기 차이를 반영합니다.
   - 정확한 타이밍일수록 성공 확률이 높아지지만, PERFECT도 결과를 완전히 보장하지 않습니다.
   - 빨간 구간은 골대에 닿지 않는 에어볼, 주황 구간은 주로 링·백보드를 맞는 슛으로 처리합니다.
   - 완벽하지 않은 슛도 확률에 따라 링이나 백보드를 거쳐 득점할 수 있습니다.

3. **1대1 공수 경쟁과 기술 조작**
   - `WASD` 이동, `Shift` 빠른 이동을 사용합니다. `Space`는 공 소유 시 슛, AI가 공을 가지고 있을 때 스틸, AI가 슛한 공이 비행 중일 때 블록으로 동작합니다.
   - 플레이어가 공을 가지고 있지 않고 AI가 공을 가진 상태에서 가까이 붙어 `Space`를 한 번 누르면 스틸을 시도합니다. Q 입력은 필요하지 않습니다. 성공 여부는 거리·확률·재시도 대기시간을 따르며, 길게 누른 키 반복으로 연속 스틸하지 않습니다. 바닥의 공은 접근해서 회수합니다.
   - 공격 중 `Alt`를 누르면 공의 드리블 위치가 오른쪽과 왼쪽 사이에서 바뀌며, 타이밍이 맞으면 AI의 스틸을 피할 수 있습니다.
   - AI도 가까운 거리에서 자율적으로 스틸과 블록을 시도하고, 실패 공을 잡으면 드리블해 공격한 뒤 슛합니다.
   - AI는 플레이어와 골대 사이를 지키되 그대로 따라다니지 않으며, 두 캐릭터가 겹치면 좌우 수비 각도를 바꾸고 자연스럽게 간격을 확보합니다.
   - 플레이어와 AI 중 먼저 7점을 얻은 쪽이 승리합니다.
   - 득점 후 공수가 바뀌면 새 공격자는 기존 시작 위치(중앙 바깥쪽), 수비자는 골대 쪽 수비 위치에서 시작합니다. 플레이어 득점 시 AI가 바깥쪽에서 공을 갖고 시작합니다.

4. **리바운드·레이업·덩크**
   - 실패한 공은 자동으로 소유권이 바뀌지 않고 코트로 튀어나옵니다.
   - 플레이어와 AI 중 공이 떨어진 위치에 먼저 도착한 쪽이 소유권을 얻습니다.
   - 슈팅 챌린지에서는 실패 공이 생기면 `공을 주우러 가세요` 안내가 나타나고, 공을 회수하면 사라집니다.
   - 공을 가진 채 골대 바로 앞(골대 중심까지 약 1.6m 이내)에 접근하면 ‘덩크 가능’ 안내가 표시됩니다. Space를 누르다가 초록 구간에서 놓으면 덩크를 시도합니다. 준비·도약·링 위에서 공을 내려꽂는 동작으로 표현하며, 타이밍과 수비에 따라 실패할 수 있습니다.  자유투 박스 안에서 골대로 이동하며 맞추면 레이업을 시도합니다.

5. **세 모드와 참여자 랭킹**
   - **1대1:** AI와 먼저 7점을 얻기 위해 경쟁하며 오른쪽에 경기 경과 시간을 표시합니다.
   - **슈팅 챌린지:** 60초 동안 일반 슛, 머니볼과 연속 성공 보너스로 최고 점수에 도전합니다. 골대·백보드·기둥과 판정 위치는 1대1보다 코트 안쪽에 있어 연습하기 조금 더 가깝습니다.
   - 메인 화면의 별도 `랭킹` 버튼에서 AI 1대1 승리 기록, 친구 대전 승리 기록, 슈팅 최고 점수를 나눠 표시합니다.
   - 같은 브라우저에서 이름을 바꿔 플레이하면 참여자별 기록이 각각 쌓입니다. 기존 승리·최고 점수는 보존합니다.
   - 선수 이름별·모드별 시도 수와 성공 수를 누적 저장하고, 랭킹에 누적 성공률을 표시합니다. 각 슛을 시작하거나 성공했을 때 바로 저장합니다. 과거 버전에서 수집하지 않은 성공률은 추정하지 않습니다.
   - 결과 화면에는 이번 경기 성공률, 누적 성공률, 가까운·중간·먼 거리별 성공률을 표시합니다. 시도하지 않은 거리는 ‘—’로 표시합니다.
   - 60초 안에 던졌지만 종료 시점까지 해결되지 않은 슛은 시도 횟수에는 포함되고 성공에는 포함되지 않습니다.

6. **일시정지와 조작 가이드**
   - 화면의 ‘일시정지 · P’ 버튼과 ‘P / Esc’ 안내를 제공합니다. P 또는 Esc로 일시정지·재개할 수 있습니다.
   - 다른 탭·창으로 이동할 때 자동 정지는 유지합니다. 시간·선수·공·슛 진행이 멈추고, 재개 버튼 또는 P/Esc로 이어갑니다. 준비 중 슛은 취소하므로 재개 시 Space를 다시 눌러야 합니다.
   - 메인 화면 별도 ‘조작 가이드’ 버튼에서 36초 자동 재생 데모를 제공합니다. 이동 → 거리별 세기 → 실패 공 회수 → 득점 → 골대 접근·덩크 게이지·덩크 시연 → 일시정지를 자막과 함께 보여줍니다.
   - 데모는 재생·일시정지·처음부터·모드 선택 기능을 제공하고 실제 경기 점수·랭킹에는 영향을 주지 않습니다. 실제 촬영 영상 파일이 아닌 게임 그래픽을 이용한 재생형 안내입니다.

- **컴퓨터 선수에게 맡길 것:** 수비 위치 선정, 좌우 간격 조절, 스틸·블록·리바운드 판단, 공을 얻은 뒤 드리블과 슛 결정
- **사람이 확인할 것:** 조작감, AI 난이도와 자연스러움, 골대 거리, 슛 확률, 리바운드 안내의 이해도, 캐릭터 외형과 랭킹 표시

## v14 선수 방향과 한 키보드 2인 대전

- 모드는 VS CPU(AI 1대1), LOCAL 1V1(친구 1대1), SHOOTING(슈팅 챌린지)으로 구분합니다. 기존 AI와 슈팅 모드를 보존합니다.
- 실제 경기의 공 소유자와 슈터는 골대를 향한 뒷모습(뒷머리·유니폼 뒤 이름과 등번호), 수비자는 정면으로 표현합니다. 슛 이후 리바운드 상황은 직전 공격 방향을 유지합니다. 설정 화면은 외형 확인을 위해 정면을 유지합니다.
- 로컬 준비 화면에서 두 선수의 이름·국가·피부색·헤어·장비·등번호를 각각 설정하고 같은 브라우저에 저장합니다. 기록 혼동을 막기 위해 이름은 서로 달라야 합니다.
- 1P: WASD 이동, Shift 빠르게, Space 슛/스틸/블록, Alt 크로스오버.
- 2P: 방향키 이동, 숫자 2 빠르게, 숫자 0 슛/스틸/블록, 숫자 1 크로스오버. 숫자 윗줄과 숫자패드를 모두 지원합니다. P/Esc는 공통 일시정지입니다.
- 공 소유 시 슛 버튼을 누르고 초록 구간에 놓기, 미소유 시 같은 버튼으로 스틸·상대 슛 블록을 수행합니다. 양쪽 모두 확률형 슛·덩크·레이업·크로스오버·리바운드를 사용할 수 있습니다.
- 한 개의 슛 게이지를 공 소유자에게 연결하며 누구의 게이지인지 표시합니다. 상대의 키를 놓아도 공격자의 슛은 발사되지 않습니다.
- 로컬 모드에서는 AI 자동 이동·슛·스틸을 호출하지 않습니다. 선수끼리 겹치지 않도록 분리하고 공 회수는 가까운 선수부터 판정합니다.
- 먼저 7점을 얻으면 종료합니다. 득점 이후 새 공격자는 바깥 시작 위치, 수비자는 골대 쪽에서 시작합니다. 결과에는 두 이름과 점수·각 선수 성공률을 표시합니다.
- 로컬 승리·경기 수 및 선수별 슛 성공률은 별도 모드로 누적합니다. 기존 AI·슈팅 기록을 섞거나 초기화하지 않습니다. 온라인 대전 기록은 별도 온라인 랭킹으로 구분합니다.

## v14 최신 변경 — 2026-09-11

### 3점선 체크 규칙 (VS CPU·LOCAL·ONLINE)
- 상대에게서 공을 얻는 스틸 또는 수비 리바운드마다 체크가 필요합니다. 공을 가진 선수가 코트에 그려진 3점선 바깥으로 나가면 체크 완료입니다. 공 없이 밖으로 나가는 것은 인정하지 않습니다.
- 체크 완료 후 다시 안으로 들어와 슛할 수 있습니다. 자기 슛의 공격 리바운드는 체크 상태를 유지합니다.
- 체크 전 넣은 골은 0점, 성공 기록 및 GOAL/PERFECT·덩크 임팩트 없음. 작은 ‘득점 무효’ 안내가 3.2초 표시되고 상대가 바깥 시작 위치에서 공격합니다.
- 슛을 놓은 순간의 체크 상태로 판정합니다. 슛 이후 밖으로 뛰어나가도 이전 슛이 유효해지지 않습니다.
- 득점 뒤 새 공격자는 이미 3점선 밖에서 시작하므로 체크가 완료된 상태입니다. AI도 수비 리바운드·스틸 후 밖으로 이동하고 공격합니다.
- 슈팅 챌린지는 체크 규칙을 적용하지 않습니다. 경기 상단 작은 안내, 로컬 준비 화면, 온라인 설명, 가이드의 00:28 공수 교대 구간에 반영합니다.

### 주로 쓰는 손
- 선수 설정에 오른손잡이·왼손잡이를 추가합니다. 이전 저장 데이터는 오른손잡이가 기본값입니다.
- 두 로컬 선수는 독립적으로 저장하며 온라인에서도 각자 설정한 주손을 상대에게 전달합니다.
- 일반 슛·레이업의 공 출발 위치와 주도하는 팔, 덩크와 기본 드리블 방향에 반영합니다. 크로스오버로 현재 드리블 손을 바꾸어도 슛은 설정한 주손을 사용합니다.

### ONLINE 1V1 — 별도 컴퓨터 친구 초대
- 기존 VS CPU·LOCAL 1V1·SHOOTING을 유지하고 ONLINE 1V1을 별도 추가합니다.
- 방장: 방 만들기 → 생성된 무작위 영문·숫자 8자리 코드 공유 → 상대 이름 확인 → 경기 시작. 참가자: 자기 선수 설정 → 코드 입력 → 입장 → 방장 시작 대기.
- 두 사람 모두 자기 컴퓨터에서 WASD, Space 슛·수비, Alt 크로스오버, Shift 빠르게를 사용합니다. 방장은 파랑 1P, 참가자는 빨강 2P입니다.
- PeerJS 1.5.5를 HTML에 포함합니다. PeerServer Cloud가 연결을 중개하고 WebRTC 데이터 연결로 방장이 공·선수·득점 상태를 약 30회/초 전달합니다. 참가자는 조작 입력만 보내며 자신의 점수를 보내지 않습니다.
- 한 방은 두 명만 허용합니다. 코드 오류·이미 찬 방·연결 실패·시간 초과·상대 종료를 표시합니다. 연결이 끊긴 미완료 경기는 승패로 기록하지 않습니다.
- P/Esc, 정지 버튼, 탭 이탈은 두 사람의 경기를 멈춥니다. 정지를 요청한 선수들이 재개해야 이어집니다. 재경기는 두 사람의 동의 후 시작합니다.
- 각자의 이름·외형·국가·주손·조작·경기 상태를 상대와 공유합니다. 카메라·마이크·실제 개인정보는 사용하지 않습니다.
- 완료 경기의 본인 승리·경기 수·성공률은 각 브라우저의 별도 온라인 랭킹에 누적합니다. 기존 AI·슈팅·로컬 기록과 저장 키를 보존합니다. 온라인 모드도 공용 랭킹 저장소에 누적합니다.
- 방장의 브라우저가 경기 진행을 맡으므로 방장이 닫으면 종료됩니다. 전용 중계 서버나 자동 재접속은 제공하지 않습니다. 일부 학교·회사망, 방화벽 또는 대칭 NAT에서는 연결이 안 될 수 있으며 네트워크 지연에 따라 조작감이 달라집니다.
- 배포는 기존 공개 상태를 유지합니다. 단일 실행 파일 `index-v14.html`, Sites용 `site-v09/src/index.html`.
