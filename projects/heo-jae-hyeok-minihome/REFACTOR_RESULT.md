## 2. 실제로 바꾼 내용

1. `lib/minihome.ts`에 화면과 서버가 함께 쓰는 타입, 기본 설정, 유튜브 링크 해석, 응답 처리, 방명록·다이어리 요청 함수를 모았습니다.
2. `components/minihome/overview.tsx`에 상단 바, 프로필, 방문 그래프, 알프스 소개 영역을 분리했습니다.
3. `/api/settings`와 화면에 중복되어 있던 유튜브 링크 해석 함수를 하나로 합쳤습니다.
4. 관리자 바에 펼침 상태를 설명하는 `aria-expanded`와 연결 대상을 추가했습니다.
5. 방문 그래프에 합계 설명을 추가하고 다이어리·방명록 목록에 로딩 상태를 알리는 `aria-busy`를 추가했습니다.
6. `scripts/refactor-self-check.mjs`에 유튜브 링크 형식 4개의 재실행 가능한 검사를 남겼습니다.
